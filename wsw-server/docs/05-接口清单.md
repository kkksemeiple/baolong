# 后端接口清单（90 个）

> 前端 `vue-wsw` 共调用 87 个，后端在此基础上多提供 3 个辅助接口：
> `GET /conversations/{id}`（单个会话详情）、`GET /tasks/{id}/bargains`（议价历史）、
> `GET /posts/{id}/replies`（回帖列表，前端另有调用方式）。

- 生成方式：扫描 `src/main/java/com/baolong/wsw/controller/*.java` 的映射注解自动汇总
- 通用约定：除白名单外均需 `Authorization: Bearer <token>`；写请求可带 `Idempotency-Key`
- 统一响应：`{ "code": 0, "message": "ok", "data": ... }`，`code !== 0` 即业务失败
- 未登录返回 **HTTP 401**（前端据此清凭证跳登录页），其余业务错误均为 HTTP 200 + 非 0 code
