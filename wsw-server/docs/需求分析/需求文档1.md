## 一、项目概述

### 1.1 项目定位

「暴龙万事屋」是一个面向校园的**委托互助平台 + 社区论坛**：

- 用户发布委托任务（代取、代买、租赁、家教等），其他用户接取并完成；
- 提供论坛，供用户分享日常、提问与回复；
- 提供任务详情页内的一对一实时沟通能力；
- 管理员（暴龙管理员）负责用户管理、内容审核与数据统计。

### 1.2 角色

| 角色 | 说明 | 依据 |
|---|---|---|
| 未注册用户 | 可浏览，不可发布/接取；有独立入口 | 需求 1000084 |
| 注册用户 | 可发布委托、接取委托、使用论坛与消息 | 需求 1000059 |
| 管理员（暴龙管理员） | 用户管理、内容审核、数据统计 | 需求 1000100~1000103 |

### 1.3 核心业务链路（依据现有需求推导）

```
注册 / 登录 → 发布任务 → 任务进入大厅
                              ↓
浏览任务大厅 → 搜索 / 筛选 → 查看任务 → 消息沟通 →（议价）→ 接取任务 → 完成
```
